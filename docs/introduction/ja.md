# Neck Upgrade — 健康的な閲覧習慣を支える Chrome 拡張機能

Neck Upgrade は、やさしい姿勢リマインダーと日々の学びを組み合わせた Chrome の新しいタブ用拡張機能です。新しいタブを開くと、時計、カレンダー、名言、選択したコンテンツをまとめて確認できます。通常のウェブサイトでは、**ページ揺れ**を有効にできます。これは、ゆっくり制御されたページの傾きで、視線や姿勢を変えるきっかけを作る機能です。

> 本拡張機能は日常的な姿勢リマインダーと軽いトレーニング補助を目的としています。医療機器ではなく、専門家による診断や治療の代替にはなりません。めまい、不快感、痛みを感じた場合は、直ちに回転効果を停止し、専門家に相談してください。

## 主な機能

- **調整可能な姿勢リマインダー**：新しいタブには通常、トレーニング、読書、強化、詳細モードがあります。詳細モードでは最大角度と切り替え間隔を設定できます。
- **ページ揺れ**：現在の通常ウェブページを滑らかに傾けます。0°～180°、固定またはランダムな角度、1 秒～60 分の周期、次回変更までのカウントダウンに対応しています。
- **ドメインの許可・ブロックリスト**：許可リストが空の場合、通常のウェブページでは既定で利用できます。許可リストが設定されると、登録済みドメインだけで利用できます。ブロックリストが常に優先され、サブドメインにも適用されます。
- **時刻と伝統暦**：現在時刻、西暦、旧暦、次の休日に加え、干支、生肖、二十四節気、日ごとの宜忌、彭祖百忌を確認できます。
- **毎日のコンテンツハブ**：歴史、詩歌、英語、中国語の基礎、トレンドを切り替え、更新してさらに読み進められます。
- **多言語インターフェース**：言語とテーマは新しいタブ、設定、ポップアップで同期されます。
- **3 つのテーマ**：ライト、ダーク、システム。

## コンテンツカテゴリー

### 今日の歴史

当日の重要な歴史的出来事、祝日、習慣を確認できます。Wikipedia または Baidu Baike を優先ソースとして選択でき、優先ソースから有効な内容を取得できない場合は、もう一方のソースを自動的に試します。

### 詩歌と古典

中国の詩歌と散文を、詩、詞、古典、初等教材、随筆のカテゴリーや出典で閲覧できます。『詩経』『楚辞』、唐詩、宋詞、『論語』『孟子』『大学』『中庸』『増広賢文』『千字文』『幽夢影』などを収録しています。読書の進捗はローカルに保存されるため、更新後も続きを楽しめます。

### 英語

高頻度の英単語リストで学習できます。オンライン辞書のデータが利用できる場合は、発音記号、音声、品詞、定義も表示されます。辞書サービスが利用できない場合でも、基本の単語は表示できます。

### 中国語の基礎

「すべて」「成語」「漢字」「しゃれことば」「単語」の 5 つの表示方法で、中国語と文化の知識を深められます。しゃれことばと単語は、一度に 4 件ずつ表示され、短時間の復習に適しています。

### トレンド

Weibo、Xiaohongshu、Toutiao、Zhihu、Bilibili、Google ニュース、Baidu、36Kr、V2EX などの公開プラットフォームから人気の話題を確認できます。利用可否は第三者サイト、ログイン状態、ネットワーク環境、サイト変更の影響を受けます。

### 名言

ランダムな名言が、読書や仕事の合間に短い気づきを与えます。読書モードでは名言エリアを強調し、他のインターフェース領域は水平に保ちます。

## ページ揺れについて

ページ揺れは、手動で有効にした後に現在のタブだけへ適用されます。角度と周期は視覚的に調整できます。周期スライダーは段階的な精度を採用しており、短い周期は秒単位、長い周期はより大きな刻みで設定できます。ページの再読み込みや移動後は、もう一度有効にしてください。

Chrome のセキュリティ上の制約により、`chrome://` ページ、拡張機能ページ、その他の通常ではないウェブページではページ揺れを利用できません。

## データとプライバシー

- 設定、読書の進捗、コンテンツキャッシュはローカルのブラウザーに保存されます。
- 本拡張機能には独自のアカウントシステムはなく、これらのローカル設定をプロジェクト運営サーバーへ送信しません。
- 歴史、カレンダー、辞書、名言、トレンド機能は、必要に応じて該当する公開の第三者サービスへアクセスします。ニュース、辞書の出典、フィードバックのリンクを開くと、対応する第三者サイトへ移動します。

## テーマ

- **システム**：OS のライト／ダーク設定に従います。
- **ライト**：明るい環境向けです。
- **ダーク**：暗い環境向けです。
