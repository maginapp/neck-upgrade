# 颈椎保护器（Neck Upgrade）

一款兼顾颈部活动提醒与每日知识阅读的 Chrome 新标签页扩展。打开新标签页，即可查看时间、日历、名言和你选择的内容；也可在普通网页中开启“网页摇摆”，用缓慢、可控的页面倾斜提醒自己改变观看姿势。

> 本扩展用于日常姿势提醒和轻量训练辅助，不是医疗器械，也不能替代医生的诊断或治疗。使用时如感到眩晕、不适或疼痛，请立即关闭旋转效果并咨询专业人士。

## 功能亮点

- **可调节的颈部活动提醒**：新标签页提供普通、训练、阅读、强化和高级模式；高级模式可设置最大角度与切换间隔。
- **网页摇摆**：可对当前普通网页启用平滑倾斜，支持 0°–180° 角度、固定角度或随机角度，以及 1 秒至 60 分钟的变化周期与剩余倒计时。
- **域名黑白名单**：白名单为空时，普通网页默认可用；白名单非空时仅白名单域名可用；黑名单始终优先。规则同时适用于子域名。
- **时间与传统日历**：显示实时时间、公历、农历、下一个休息日；可查看干支、生肖、节气、每日宜忌、彭祖百忌等信息。
- **每日内容中心**：在历史、诗词、英语、中文基础和热榜之间切换，并可通过刷新继续浏览内容。
- **五种界面语言**：简体中文、繁體中文、English、Русский、Français；语言与主题会在新标签页、设置页和 Popup 中同步。
- **三种主题**：亮色、暗黑和跟随系统，适配不同使用环境。

## 内容分类

### 历史上的今天

查看当日重要历史事件、节假日与习俗。可选择维基百科或百度百科作为优先来源；当首选来源无法取得有效内容时，扩展会自动尝试备用来源。

### 诗词与经典

内置中国古典诗文，可按大类和具体来源筛选：诗歌、词、经典、蒙学与文人小品，涵盖《诗经》《楚辞》、唐诗、宋词、《论语》《孟子》《大学》《中庸》《增广贤文》《千字文》《幽梦影》等。内容学习进度保存在本机，便于在后续刷新时继续阅读。

《千字文》按语义小节展示，并采用每行八个汉字的排版，阅读更连贯。

### 英语

从高频英语词表中提供每日学习内容。网络可用时，单词还可显示音标、发音、词性和释义；词典服务不可用时，基础单词仍可展示。

### 中文基础

面向中文学习与文化积累，支持“全部、成语、汉字、歇后语、词语”五种浏览方式。其中歇后语和词语一次展示四条，便于快速阅读与记忆。

### 热榜

聚合多个公开平台的热门内容，支持在微博、小红书、今日头条、知乎、Bilibili、Google 新闻、百度、36 氪和 V2EX 等来源及分类间切换。热榜内容来自第三方站点，具体可用性可能受登录状态、网络环境或站点调整影响。

### 名人名言

随机展示名言，为阅读与工作间隙提供一条简短提示。阅读模式会突出显示名言区域，同时保持其他界面不旋转。

## 网页摇摆说明

网页摇摆仅在你主动开启后作用于当前标签页。它支持对角度和变化周期进行可视化调整：周期滑杆采用分段精度，短周期可按秒设置，较长周期按更大步长设置，既便于精细调整，也避免过长的滑动距离。刷新页面、跳转到新页面后，需要重新开启。

出于 Chrome 安全限制，`chrome://` 页面、扩展页面和其他非普通网页不支持网页摇摆。

## 数据与隐私

- 设置、学习记录和内容缓存保存在当前浏览器本地。
- 扩展没有自建账号体系，不会将这些本地设置上传至项目自有服务器。
- 历史、日历、词典、名言与热榜等功能会按需访问相应的第三方公开服务；点击新闻、词典来源或反馈链接后，将进入对应第三方网站。

## 主题模式

- **系统**：自动跟随操作系统的亮色或暗色设置。
- **亮色**：适合明亮环境。
- **暗黑**：适合低光环境。
