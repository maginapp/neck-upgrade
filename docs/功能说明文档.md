# 颈椎保护器功能说明文档

> 适用版本：1.2.5 ｜ 文档依据：当前已实现功能

## 1. 产品定位

颈椎保护器是一款替换 Chrome 新标签页的健康与信息聚合扩展。它会让核心内容以不同角度显示，提醒用户改变长期固定的观看姿势；同时把日历、传统文化、学习内容和热门资讯集中到每次打开新标签页的场景中。

适合希望在日常浏览中获得轻量颈部活动提醒，并顺便阅读知识、诗词、英语或热点内容的用户。

> 本扩展提供的是姿势提醒与训练辅助，不属于医疗器械，也不替代专业诊断或治疗。若旋转显示引起不适，应切换普通模式或停止使用。

## 2. 页面组成

新标签页包含四个主要区域：

1. 顶部日期区：当前时间、公历日期、农历与下个休息日；
2. 侧边名言区：随机展示一条名人名言；
3. 中心内容区：历史、诗词、英语或热榜；
4. 设置入口：右侧设置按钮，打开主题、旋转模式和内容设置。

当浏览器窗口较小时，中心区域会自动缩放以适应可用空间。

## 3. 颈椎倾斜模式

| 模式   | 用户体验                                                     | 自动切换   |
| ------ | ------------------------------------------------------------ | ---------- |
| 普通   | 小角度倾斜，适合希望画面相对稳定的用户                       | 否         |
| 训练   | 在小角度范围内定时变化，默认模式                             | 每 5 秒    |
| 阅读   | 主区域显示名人名言，仅名言小角度倾斜，日期和其他界面保持水平 | 每 5 秒    |
| 强化   | 使用更大的旋转角度，可能出现接近倒置的画面                   | 每 5 秒    |
| 自定义 | 自行设置最大旋转角度和切换间隔                               | 按用户设置 |

自定义模式支持：

- 切换间隔：0–60 秒；设为 0 时不自动切换；
- 最大旋转角度：0°–360°。

设置完成后立即生效，并在之后打开新标签页时保留。

## 4. 日期与传统日历

页面实时显示时、分、秒，以及年月日和星期。农历区域显示当天农历日期，点击旁边的详情图标可以查看：

- 干支年、月、日及生肖；
- 公历与农历节日；
- 当前节气及所处天数；
- 每日宜、忌；
- 儒略日；
- 彭祖百忌；
- 梅雨信息（当天存在时显示）。

页面还会显示距离下一个休息日的天数和休息日名称。时间每秒更新，日期改变后相关日历数据会自动刷新。

## 5. 内容中心

### 5.1 历史

展示“历史上的今天”的事件以及当天节假日和习俗。用户可以在设置中选择优先使用维基百科或百度百科；首选来源失败或没有有效内容时，扩展会自动尝试另一个来源。

单次最多展示 8 条历史事件和 2 条节假日/习俗，内容会随机抽取。点击刷新按钮可重新获取或重新组合显示内容。

### 5.2 诗词

诗词数据内置于扩展，不依赖网络即可读取。设置中支持按“诗歌、词、经典、蒙学、文人小品”选择一级分类，并可继续多选唐诗三百首、诗经、宋词三百首、论语、千字文等具体来源。系统每天在所选范围内准备 10 条新的诗词或古文，每次展示 2 条；点击刷新可继续查看当天的下一批内容。

卡片包含标题、作者、标签和正文。《千字文》按照篇章含义拆分为 34 个语义小节，例如“天地宇宙”“人文肇始”“家庭伦理”“九州山河”等；展示时每两个四字句合并为一行，中间使用中文逗号分隔，拼音同步合并。学习记录保存在当前浏览器中，并保留最近 30 天的历史；不同来源组合分别记录学习进度。

### 5.3 英语

系统每天从高频英语词表中选择 15 个新词，每次展示 5 个。联网成功时，单词卡片还会显示：

- 音标；
- 发音按钮；
- 词性；
- 精简后的英文释义；
- 词典来源链接。

词典服务不可用时，单词本身仍可能显示，但音标、发音或释义可能缺失。点击刷新可继续查看当天的下一批单词。

### 5.4 热榜

热榜聚合多个站点。点击平台图标切换平台；一个平台包含多个分类时，再从弹出的分类列表中选择具体榜单。新闻条目会在新标签页中打开原始链接。

| 平台        | 可选内容                                                                                        |
| ----------- | ----------------------------------------------------------------------------------------------- |
| 微博        | 我的、热搜、文娱、生活、社会                                                                    |
| 小红书      | 推荐                                                                                            |
| 今日头条    | 热搜                                                                                            |
| 知乎        | 热榜                                                                                            |
| Bilibili    | 综合、热榜、动画、鬼畜、音乐、舞蹈、影视、娱乐、知识、科技、美食、体育                          |
| Google 新闻 | 中文推荐/中国/全球/娱乐/体育/商业，以及英文推荐、美国、全球、科技、娱乐、体育、商业、科学、健康 |
| 百度        | 贴吧、热榜                                                                                      |
| 36氪        | 综合、热榜、股票、公司、宏观                                                                    |
| V2EX        | 技术、好玩、创意、最热、综合                                                                    |

每页默认显示 10 条。“刷新”会切换到下一页，超过数据末尾后回到第一页。榜单数据缓存约 5 分钟，以减少重复请求。

部分平台可能要求用户先登录。遇到这种情况，页面会显示登录入口；平台改版、网络限制或权限配置也可能导致暂时无法取得内容。

## 6. 名人名言

页面侧边会从 ZenQuotes 和“一言”内容池中随机显示一句名言，并在有数据时显示作者或来源。每天会尝试补充内容，最多保留 30 条本地缓存。

## 7. 主题设置

扩展支持三种主题：

- 系统：跟随操作系统的亮色或暗色设置，默认选项；
- 亮色：固定使用亮色界面；
- 暗色：固定使用暗色界面。

系统主题在运行期间发生变化时，页面会自动同步。

## 8. 百科数据源设置

用户可选择维基百科或百度百科作为“历史上的今天”的优先来源。该选项只影响历史模块，不影响诗词、英语或热榜。首选源异常时仍会自动使用备用源。

## 9. 扩展 Popup 功能

点击浏览器工具栏中的扩展图标，可以：

- 在当前普通网页开启“网页摇摆”，让整个页面按设定周期在正负角度之间平滑切换；
- 开启后通过半圆仪表盘和滑杆调整页面角度（0°–180°），并设置变化周期（1 秒–60 分钟）；
- 可选择固定角度或“范围内随机”：固定模式按设定角度在左右方向间切换，随机模式每次在正负最大角度之间选择新角度；
- 在当前页面为扩展新标签页时，打开或关闭设置面板；
- 打开一个新的 Chrome 新标签页；
- 打开扩展管理页；
- 查看扩展的网站权限；
- 打开 Chrome 扩展快捷键设置；
- 前往 GitHub 提交反馈和参与讨论。

时间滑杆使用分段精度算法：1 分钟以内每格 1 秒，1–3 分钟每格 5 秒，3–5 分钟每格 15 秒，5–15 分钟每格 30 秒，15 分钟以后每格 1 分钟。每个滑杆位置都对应唯一值，越靠近右侧，相同滑动距离对应的时间增量越大。启用后状态栏会以 `MM:SS` 显示距离下次角度切换的实时倒计时。

随机角度模式会尽量避开与当前角度过于接近的新值，使每次变化保持可感知；切换固定/随机模式或调整角度不会重置倒计时，只有调整变化周期才会重新计时。

网页摇摆只作用于启用时的当前标签页，角度和周期会保存在本机供下次使用。刷新或跳转页面后需要重新开启。出于浏览器安全限制，`chrome://`、扩展页等 Chrome 内部页面不支持该功能。

## 10. 数据、权限与隐私说明

扩展将用户设置、内容缓存和学习进度保存在本机浏览器中。当前代码未实现自建账号体系，也不会把这些本地设置同步到项目自有服务器。

为取得页面内容，扩展申请：

- `storage`：保存设置之外的内容缓存和学习记录；
- `activeTab`：识别当前活动页并与扩展新标签页交互；
- `scripting`：在用户主动开启网页摇摆时，将本地内容脚本注入当前标签页；
- 数据站点访问权限：请求维基百科、百度百科、Timor、词典、名言和各热榜平台。

点击新闻、词典来源、登录、反馈等链接后，将进入对应第三方网站，其数据处理遵循该网站自己的规则。

## 11. 缓存与更新规则

| 内容          | 更新规则                         |
| ------------- | -------------------------------- |
| 用户设置      | 一直保留，直到浏览器数据被清除   |
| 历史与习俗    | 每个自然日更新                   |
| 下个休息日    | 每个自然日更新                   |
| 热榜          | 约 5 分钟更新                    |
| 诗词/英语计划 | 每个自然日生成新内容并记录进度   |
| 名人名言      | 每天尝试补充，随机展示本地内容池 |

若希望立即获得不同内容，可使用各内容区的刷新按钮；刷新不一定绕过缓存，具体表现取决于内容类型。

## 12. 常见问题

### 为什么页面是倾斜的？

这是产品的核心训练方式。可以打开设置，切换到普通模式，或在自定义模式中把最大角度和切换间隔调低。

### 为什么历史内容来源与我的设置不同？

首选百科来源获取失败或内容为空时，扩展会自动使用备用来源，并在标题旁显示实际来源。

### 为什么英语只有单词，没有释义或发音？

基础词表位于扩展本地，但释义和音频来自在线词典。网络或词典服务不可用时，这些附加信息可能缺失。

### 为什么某个热榜为空或要求登录？

热榜依赖第三方站点，可能受到登录态、站点改版、地区网络和访问频率影响。可按提示登录、切换其他分类或稍后重试。

### 为什么点击刷新看到的是下一批而不是全新抓取？

诗词和英语的刷新用于推进当天学习批次；热榜刷新用于翻到下一页；历史刷新可能复用当天缓存后重新随机展示。

### 如何恢复默认设置？

当前界面没有“一键恢复默认”按钮。可手动切回系统主题、训练模式、历史内容和维基百科优先；清除扩展相关浏览器数据也会重置设置与学习记录。
