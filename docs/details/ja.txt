ネックアップグレード：首の健康習慣を支える Chrome 拡張機能

ネックアップグレードは、首の運動リマインダー、カレンダー情報、毎日の学習コンテンツを組み合わせた Chrome の新しいタブ用拡張機能です。調整可能なページ傾斜とページ揺れで視線や姿勢を変えるきっかけを作り、履歴、詩詞、英語、中国語基礎、話題の情報を新しいタブに届けます。

注意：本拡張機能は日常の姿勢リマインダーと軽いトレーニング補助を目的としています。医療機器ではなく、専門的な診断や治療の代わりにはなりません。めまい、不快感、痛みを感じた場合は、すぐに回転効果を停止し、専門家に相談してください。

主な機能
✔️ 標準、トレーニング、読書、強化、詳細カスタムの首傾斜モード
✔️ ページ揺れ：現在の通常ウェブページをなめらかに傾け、角度、周期、固定／ランダム角度を設定可能
✔️ ドメインの許可リスト／ブロックリスト：サブドメイン照合に対応し、ブロックリストを優先
✔️ 現在時刻、旧暦、次の休みを表示
✔️ 干支、十二支、二十四節気、宜忌、彭祖百忌、休日と風習を含む伝統暦
✔️ 「歴史上のこの日」：Wikipedia は表示言語に合わせて取得し、自動フォールバック
✔️ 古典詩詞と古文：多段階の分類と出典フィルター
✔️ 毎日の英単語、発音記号、発音、意味
✔️ 中国語基礎：成語、漢字、歇後語、単語
✔️ 主要プラットフォームのトレンド。Google ニュースは表示言語と地域に連動
✔️ 組み込みデータとローカル学習履歴を対象にしたあいまい検索
✔️ 毎日の名言、多言語インターフェース、複数テーマ

テーマ
✔️ ライト：日中向けの明るく見やすい表示
✔️ ダーク：暗い環境で快適な読書体験
✔️ システム：OS のライト／ダーク設定に自動追従（初期設定）

首傾斜モード
✔️ 標準：見た目を安定させたい人向けの小さく快適な傾斜
✔️ トレーニング：小さな傾斜を定期的に変え、同じ姿勢の継続を防止（初期設定）
✔️ 読書：メイン領域に名言を表示し、名言領域だけを軽く変化させ、他の UI は水平に維持
✔️ 強化：傾斜トレーニングに慣れた人向けの大きな回転角度
✔️ 詳細：最大回転角度と切替間隔を設定でき、即時に反映してローカル保存

ページ揺れ
✔️ ブラウザツールバーの Popup から有効化。現在の通常ウェブページタブだけに適用
✔️ 0°～180° の角度を視覚的に調整し、固定または正負の最大範囲でランダムに変更
✔️ 周期は 1 秒～60 分。短い周期は秒単位、長い周期はより大きい刻みで調整
✔️ 次回切替までのカウントダウンを表示
✔️ ブロックリスト優先。許可リストが空なら通常ページを許可し、空でなければ登録ドメインだけを許可
✔️ Chrome の内部ページ、拡張機能ページなど、ブラウザの制限対象ページには非対応

コンテンツ分類
✔️ 詩詞と古典：毎日新しい読書コンテンツを用意し、直近 30 日の学習履歴を保存。詩、詞、古典、蒙学、随筆、出典で絞り込み可能です。《詩経》《楚辞》、唐詩、宋詞、《論語》《孟子》《大学》《中庸》《増広賢文》《千字文》《幽夢影》などを収録。《千字文》は意味ごとの節に分け、1 行 8 漢字で表示します。
✔️ 歴史：この日の歴史的出来事、祝日、風習を表示。Wikipedia または百度百科を優先ソースに選べます。Wikipedia は現在の言語で取得し、内容がなければ英語、次に中国語へフォールバックします。
✔️ 英語：高頻度語彙リストから毎日の学習項目を表示。オンライン時は発音記号、音声、品詞、意味を表示し、進捗はローカル保存します。
✔️ 中国語基礎：すべて、成語、漢字、歇後語、単語を閲覧可能。歇後語と単語は 1 回に 4 件表示します。
✔️ トレンド：Weibo、Xiaohongshu、Toutiao、Zhihu、Bilibili、Google ニュース、Baidu、36Kr、V2EX などを集約し、約 5 分ごとに更新。一部のソースはログイン、ネットワーク、サイト変更の影響を受ける場合があります。
✔️ 名言：ローカルのコンテンツプールからランダムに表示。読書モードではこの領域を強調します。

検索
✔️ 設定ボタンの左側に検索入口があり、部分一致と文字順あいまい一致に対応
✔️ 組み込みデータ：詩詞、中国語基礎、英単語リスト
✔️ 履歴：ローカルに保存した詩詞、英語、中国語基礎の学習履歴
✔️ 結果は「組み込みデータ／履歴」の 2 タブで表示

言語とインターフェース
✔️ 簡体字中国語、繁体字中国語、英語、ロシア語、フランス語、日本語、アラビア語に対応
✔️ メインの言語ボタンで固定順に切替、ドロップダウンから直接選択も可能
✔️ アラビア語では RTL レイアウトを自動適用。検索、設定、設定ドロワーは右側に維持し、ドメインと URL の入力欄は編集しやすい LTR を維持

百科事典ソース
✔️ Wikipedia：既定のソース。多言語取得と英語／中国語へのフォールバックに対応
✔️ 百度百科：中国語ソース

データとプライバシー
✔️ 設定、学習進捗、ドメインルール、コンテンツキャッシュは現在のブラウザにローカル保存
✔️ アカウントシステムはなく、これらのローカルデータをプロジェクト所有サーバーへ送信しません
✔️ 履歴、暦、辞書、名言、トレンド機能は必要に応じて第三者の公開サービスにアクセスします。ニュース、辞書、フィードバックのリンクを開くと、該当する第三者サイトへ移動します。
